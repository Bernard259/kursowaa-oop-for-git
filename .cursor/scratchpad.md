# Background and Motivation
- Добавить в игру визуальный показатель локального рекорда (best score) в правом углу интерфейса.
- Рекорд должен сохраняться между запусками игры локально на компьютере пользователя.

# Key Challenges and Analysis
- Нужно хранить рекорд отдельно от текущего счёта раунда.
- Данные должны переживать перезапуск процесса, значит требуется чтение/запись в файл.
- Отображение должно быть компактным и не конфликтовать с существующей строкой заголовка.
